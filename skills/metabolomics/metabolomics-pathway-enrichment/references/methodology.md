# Methodology

Matching is case-insensitive exact name equality, not substring matching. The background is the union of reference members. Hypergeometric survival probabilities and BH correction apply to pathways with at least one hit, matching the legacy CLI.

`enrich` implements only ora and rejects fella/mummichog. It requires explicit `pathways=`; `demo_pathways()` selects illustrative sets only for demonstrations. Real CLI input requires `--pathway-file`. `tables/pathway_enrichment.csv` has a stable schema even with no overlap.
