下面的命令都在仓库根目录执行，适用于 Linux 和 macOS。

## 1. 安装

```bash
git clone https://github.com/TianGzlab/OmicsClaw.git
cd OmicsClaw
bash 0_setup_env.sh
conda activate OmicsClaw
```

`0_setup_env.sh` 优先用 `mamba`，找不到时回退到 `conda`。它按 `environment.yml` 建一个名为 `OmicsClaw` 的环境，装入 R 4.3 与 R/Bioconductor 包、samtools、STAR、fastqc 等命令行工具和 Python 科学计算栈，再以可编辑模式安装 OmicsClaw 及其 `full`、`singlecell-upstream` extra，`oc` 命令随之可用。整个过程通常要 10 到 30 分钟，取决于网络和镜像速度。想用别的环境名，运行 `bash 0_setup_env.sh <环境名>`。

确认技能已就位：

```bash
make list
```

第一行应为 `94 skill(s), 0 skipped`，下面按领域列出 7 个领域的技能名。

## 2. 配置模型

```bash
oc cli --configure
```

向导先让你选 provider（13 个预设，默认 `deepseek`），再依次询问 API key、模型 id、base URL 和工作区目录。base URL 留空就用预设的地址；本地的 `ollama` 不问 API key。之后可以选择配置 Telegram、飞书和桌面端的 bearer token，不用的直接跳过。结果写入仓库根目录的 `.env`，已有的 `.env` 会先另存为 `.env.backup-<时间戳>`。`--configure` 只写配置，不启动 agent。

不用向导也可以：把 `.env.example` 复制为 `.env`，手工填写 `LLM_PROVIDER`、`LLM_API_KEY`、`LLM_MODEL` 和 `LLM_BASE_URL`。

工作区是 agent 可以读写的目录，向导默认填当前目录。agent 从 `<工作区>/skills` 读取技能，所以工作区不是仓库检出目录时，要在 `.env` 里设置 `OMICSCLAW_SKILLS_DIR=<检出目录>/skills`，否则 agent 看不到任何技能。

## 3. 和 agent 对话

```bash
oc cli
```

这会打开终端里的 REPL。输入 `/` 查看可用命令，`/help` 列出全部命令。

只问一次、拿到回答就退出：

```bash
oc cli --prompt "用 demo 数据跑一次 spatial-preprocess，并总结结果"
```

较长的问题可以写进文件，用 `oc cli --prompt-file brief.md` 传入。`oc cli --help` 列出全部参数。

没有配置 API key 时 `oc cli` 照样能启动，启动时会在 stderr 提示运行 `oc cli --configure`，但对模型的调用都不会成功。

## 4. 直接运行技能 demo

技能是普通的 Python 脚本，不经过 agent 也能运行。大多数技能支持 `--demo`，用内置或现场生成的演示数据，不需要准备输入文件：

```bash
python skills/spatial/spatial-preprocess/spatial_preprocess.py --demo --output /tmp/quickstart_demo
```

结束时终端打印 `Preprocessing complete: 200 cells, 3 clusters`。输出目录里有 `report.md`、`result.json`、`processed.h5ad`，以及 `figures/`、`tables/` 等子目录。

其他技能的脚本在各自的技能目录里，形如 `skills/<领域>/<技能>/<脚本>.py`（单细胞技能多一层 `scrna/` 或 `scatac/`），参数写在同一目录的 `SKILL.md` 里。`make demo-all` 依次跑 15 个空间转录组技能的 demo。
